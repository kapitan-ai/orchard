# Design

Validated public controls remain in the preparation call's request parameters while pure normalizers construct the ordinary unprepared canonical skeleton. After resolving the selected model and its trusted manifest, preparation resolves the closed effort registration and replaces reasoning with a fully bound rendered contract. An unbound explicit control must never reach tokenization, serialization, persistence, scheduling or dispatch. Both public endpoints share this preparation boundary.

The initial exact registration uses one artifact/template pair and maps low to low, medium to medium and high to native xhigh. The same model is retained; no effort-only reload or Catalog copy is required. A rendered contract records artifact/template/render version and native value, with canonical effort and provenance outside that identity. The helper uses the integrated legacy history allowlist and returns actual applied arguments alongside counted rendering. The Controller compares all proof fields.

The first route requires the real tokenizer port and safe mode off. Other routes reject the explicit control rather than dropping it. Omitted rendering and hash domains stay unchanged. Operator retry retains its existing refusal for explicit reasoning; automatic attempts reuse prepared input. Prefix affinity remains a ranking hint and exact token IDs protect cache correctness.

Thinking is requested by the input renderer; legacy output makes no hidden-thought, parsing, hard reasoning-budget or nonempty-thought conformance claim. Final-only retains all existing negotiated requirements. Public structured prior reasoning remains rejected. CPU/HTTP-shaped tests qualify controls and isolation; inference and semantic/support qualification remain separate.

Per-model discovery adds `orchard_reasoning_effort` to the existing tenant-scoped model list. Both discovery and binding share the exact artifact/template profile lookup and real-port/safe-mode-off predicate. Discovery reads the manifest without tool preflight; preparation preserves full verification and authorizes explicitly selected effort requests before capability resolution. Omitted effort retains the existing tooling, tokenization and context-error precedence before model authorization. Both paths authorize once before preparation succeeds. Missing evidence advertises no support. Discovery is advisory; actual helper template-byte proof and render/count remain authoritative.

The profile declares a nonempty identifier-to-native mapping and an informational default with exact-template CPU evidence. Qwen adds direct xhigh and preserves high as a documented compatibility alias. Distinct caller choices retain distinct serialized reasoning identities even when aliases render the same bytes. Existing three atoms remain compatible, additional rendered identifiers stay bounded strings, and negotiated wire enums remain unchanged. Omitted requests never consume the discovery default.
