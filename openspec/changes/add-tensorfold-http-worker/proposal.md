## Why

A full-history provider needs natural tool continuations and checkpoint reuse while retaining Orchard's authoritative token IDs and Node Agent lifecycle ownership. Passing rendered text as a user message loses the history boundary.

## What Changes

- Prepare an explicitly selected, default-off TensorFold HTTP Worker implementation with isolated dependencies; retain the default MLX-LM implementation and its locks.
- Gate the additive versioned ExecuteInferenceRequest projection on exact tokenizer-only parity with canonical natural tool history.
- Bind loaded model, artifact, template, effort and child incarnation; reject unsupported controls and mixed-version routes.
- Bound admission, streaming buffers and retained/staged state. Keep uncertain cancellation unavailable until confirmed owned process-tree reaping.

## Impact

SPEC.md's existing experimental profile excludes TensorFold as a foundation. This candidate proposes a separate default-off source experiment, not a change to the supported foundation or a production qualification. Before admission implementation the branch must explicitly reconcile that distinction in SPEC.md. No GPU execution, distribution or publication is included. Provider parity or containment failure stops implementation before protocol expansion.
