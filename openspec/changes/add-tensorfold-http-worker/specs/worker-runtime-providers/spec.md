## ADDED Requirements

### Requirement: Experimental HTTP history parity gate
An explicitly selected experimental HTTP Worker SHALL preserve authoritative Orchard token IDs for canonical natural tool history under identical verified template and resolved effort options. The default Worker implementation SHALL remain unchanged.

#### Scenario: Serializer disagreement
- **WHEN** the upstream tokenizer's template serializer produces different tool-definition IDs
- **THEN** admission remains disabled until the isolated renderer establishes exact array equality for both first turn and natural continuation

#### Scenario: Containment unavailable
- **WHEN** finite retained, staged, borrowed and transient state bounds cannot be established
- **THEN** implementation stops before the experimental request protocol is expanded
