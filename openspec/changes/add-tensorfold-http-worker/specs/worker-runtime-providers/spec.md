## ADDED Requirements

### Requirement: Experimental Worker history parity gate
An explicitly selected experimental TensorFold Worker SHALL preserve authoritative Orchard token IDs for canonical natural tool history under identical verified template and resolved effort options. The default runtime selection and foundation SHALL remain unchanged.

#### Scenario: Serializer disagreement
- **WHEN** the upstream tokenizer's template serializer produces different tool-definition IDs
- **THEN** admission remains disabled until the isolated renderer establishes exact array equality for both first turn and natural continuation

#### Scenario: Containment unavailable
- **WHEN** finite retained, staged, borrowed and transient state bounds cannot be established
- **THEN** implementation stops before the experimental request protocol is expanded

### Requirement: Raw output and owned settlement
The experimental Worker SHALL preserve opaque legacy-blended assistant output through the existing Orchard event/tool pipeline and SHALL withhold successful completion until positive engine-thread settlement. It SHALL remain unavailable after uncertain cancellation, copying, shutdown or output production.

#### Scenario: Provider HTTP split loses original spelling
- **WHEN** the stock HTTP path removes reasoning closing markers or newlines
- **THEN** the bridge uses Scheduler raw token chunks within the Node-owned Worker PID instead of reconstructing text from lossy fields

#### Scenario: Deadline expires while the consumer is stalled
- **WHEN** an admitted request deadline expires without another consumer pull
- **THEN** an independent watchdog quarantines the incarnation and requests cancellation without granting resource release or replacement admission

### Requirement: Explicit internal profile admission
The experimental Worker SHALL require a bounded internal history projection matching its loaded profile and fresh incarnation. It SHALL reject unsupported controls and structured prior reasoning without inference dispatch. Generic capabilities, public metadata and preparation redemption SHALL NOT authorize this projection.

#### Scenario: Stale loaded binding or stock Worker
- **WHEN** a projection has a stale incarnation or targets a current stock Worker
- **THEN** inference is rejected before native admission
