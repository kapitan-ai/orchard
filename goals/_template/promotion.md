# Promotion Checklist

Use this checklist before turning local goal output into durable Orchard content.

- [ ] Behavior belongs in `SPEC.md` or tests.
- [ ] Process guidance belongs in `docs/process.md`.
- [ ] Durable rationale belongs in `docs/decisions/**`.
- [ ] Structured proposed change belongs in a future verified OpenSpec change.
- [ ] Operational guidance belongs in product docs or runbooks.
- [ ] Private workbench references are removed.
- [ ] Local paths are removed or replaced with product-relative paths.
- [ ] Tool session identifiers are removed.
- [ ] Evidence is sanitized.
