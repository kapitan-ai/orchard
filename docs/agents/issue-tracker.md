# Retired Issue-Tracker Workflow

This path is a transition notice, not an active tracker adapter. The former
Matt Pocock/Wayfinder workflow is retired for Orchard. Its public map, child-ticket,
dependency, claim, and resolution instructions no longer authorize operations
and must not be ported into Linear.

Use [Tracking and Publication](../process.md#tracking-and-publication) for private
product capture, public intake, and the public-ready gate. Existing links to this
file should lead readers there, not trigger GitHub writes. An instruction to
"publish to the issue tracker" does not select a destination or grant permission.
If the private tracker is unavailable, report the blocker rather than publishing
private material elsewhere.

Git history retains the retired instructions. This notice does not migrate,
relabel, close, or otherwise change existing issues or their relationships.
