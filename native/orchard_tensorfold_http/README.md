# TensorFold Worker source experiment

This package supplies a separately selected, default-off Worker backend. It embeds TensorFold Scheduler raw chunks in one Node-owned Worker PID and reuses Orchard's gRPC service, detokenizer, tool parser and events. The historical package path retains `http`; no HTTP child is launched. The normal MLX runtime and its lockfiles remain unchanged. No public Controller dispatch route is enabled.

`orchard-worker-tensorfold --experimental-tensorfold --backend tensorfold --profile-file <local-profile.json> --socket-path <owned-socket>` is the explicit executable boundary. Node Agent remains the process owner; Controller must act through Node Agent. An operator-selected executable wrapper can supply the experiment flag and profile when Node supplies its Worker arguments. Prefix caching and observe/enforce memory sampling are disabled for this experiment; generation is stream/C1. The positive legacy prefix-cache entries hint supplied by Node is accepted as inert; only the frozen driver configuration controls TensorFold checkpoints. Existing socket paths are refused, and cleanup removes only the inode created by this executable.

The local JSON configuration has exactly three objects:

- `profile`: every `ExperimentProfile` field in `admission.py`, including exact model/version/artifact/template/tokenizer-config identities and projection/token/output/deadline limits.
- `bounds`: every `DriverBounds` field in `tensorfold_driver.py`, including fixed working/workspace/copy/checkpoint/buffer capacities and cancellation/settlement limits.
- `native`: `model_path`, `max_bundle_files`, `max_bundle_bytes`, and `prefill_step`.

There are intentionally no invented hardware bounds or model identities in an example configuration. Token/context/vocabulary limits must agree across profile and driver, and the profile deadline cannot exceed the driver deadline. Copy reservations conservatively charge a full qualified working-cache capacity and the same transient capacity before materialization. Those capacities require later native qualification; accounting reservations do not measure physical GPU allocation.

Native assembly is lazy and requires an already provisioned isolated tuple: TensorFold 0.6.6, MLX 0.32.3, MLX-LM 0.32.0, Transformers 5.14.1. The model-free package lock contains renderer/transport/test dependencies only; it neither installs this native tuple nor advances the foundation pins. The loader verifies a bounded full artifact-tree digest and bound template/config snapshots, refuses custom/remote architecture configuration, and admits only the frozen Qwen3.5 family with the Qwen3 Coder parser. The tokenizer declaration must name a file in the model entrypoint directory, matching the frozen TensorFold loader; separate tokenizer layouts are refused. Sampling uses the admitted temperature/top-p, disables provider top-k/min-p defaults and ignores ambient seed salt; greedy requests use the provider's `None` convention. Full bundle verification can extend cold startup. Runtime provision and actual native load remain qualification work.

A source-controlled caller on the owned Worker socket reads the maximum-4096-byte `tensorfold_profile_admission_json` status offer after load, verifies the selected binding, and supplies it with unmodified natural `messages`/`tools` in internal `tensorfold_history_projection_json`. Ordinary public metadata and generic capabilities cannot authorize that field. It is outside preparation redemption, which the bridge rejects. The bridge rerenders prompt and no-generation-suffix history and requires exact authoritative bytes/IDs before Scheduler submission. Explicit structured prior reasoning fields remain rejected; opaque assistant content is preserved. Thinking/medium and legacy-blended output are the only admitted profile.

Successful completion follows a positive engine-thread settlement barrier. Uncertain native work, buffer/output overflow, deadline expiration, abandoned streams or shutdown quarantines the incarnation and denies reuse while keeping custody. An independent deadline watchdog works without consumer pulls. Normal settled unload joins both Scheduler threads and retires the driver without pretending that the process was reaped. Only the external Node owner can confirm owned process-tree exit/reap and start a replacement.

Model-free tests exercise real Orchard event/tool mapping, current protobuf wire encoding and local gRPC/UDS against fake native assets, plus copy custody, token buffers, checkpoint reuse, cancellation and shutdown. Synthetic sizes/latencies are test values only. No native memory-fit, GPU drain, supported-foundation, model-quality or public-route claim follows from those results. Full application/database checks and separately authorized hardware qualification remain required before a production handoff.
